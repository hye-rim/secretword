# 숨은 단어 🔎

단어를 숨기고 **뜻이 가까운 단어**로 힌트를 내서 맞히는 단어 추리 게임. 컴퓨터와 번갈아 출제하거나, **방 코드로 친구와 온라인 대전**을 한다. [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나.

- 구조: `public/`(`index.html` + `logic.js` + `game.js` + `data/`) + `server.js`(정적 파일 + WebSocket, `ws`). 컴퓨터 대전은 브라우저에서만 돌고, 온라인 대전은 서버가 판정한다.
- 실행: `npm install` 후 `npm start` (기본 포트 3029), 시험은 `npm test`.

- **규칙** (방송 「히든 워드」를 1:1 로):
  - 처음에 각자 숨길 단어 후보 **5개**를 받는다. 1라운드에 그중 하나, 2라운드에 남은 4개 중 하나를 숨긴다.
  - 출제자는 숨긴 단어와 관련된 힌트를 하나씩 **10개** 낸다. 힌트마다 **유사도(%)**가 공개되고, **95% 이상**인 힌트가 나오면 거기서 바로 힌트 단계가 끝난다. 끝난 단계의 가장 가까운 힌트에는 ⭐. 숨긴 단어 자체만 힌트로 못 쓴다(방송처럼 나무 → 소나무 는 된다).
  - 맞히는 쪽은 답을 **하나** 쓴다. 답은 **맞음·틀림만** 알려 주고 유사도는 보여 주지 않는다. 틀리면 🧩 **피스**를 써서 하나 더 쓸 수 있다(한 판에 2개).
  - 맞히면 맞힌 쪽 **1점**, 차례 끝. 못 맞히면 출제자가 단계 점수(**1차 1점, 2차 2점, 3차 3점**)를 얻고 다음 힌트 단계로, 3차까지. **2라운드는 모든 점수 2배**. 라운드마다 컴퓨터(온라인은 무작위로 정한 쪽)가 먼저 출제.
  - 방송과 다르게 정한 것: 피스는 한 판에 2개씩 준다.
- **유사도(%)**: 방송 시즌3 본 게임 기록(자막)을 보면 방송 AI 는 **연상·여러 뜻**을 후하게 친다(나침반-북쪽 95+, 머리-미용실 95+, 자동차-바퀴 96, 대기-열 95+, 수도-건설 91.5, 손님-고객 99.8, 이별-지구 8.5). 어떤 단어 벡터도 이걸 못 따라가서 두 가지를 합쳤다.
  - **연상 목록**(`public/data/assoc.json`, 만든 곳 `tools/assoc/*.txt`): 정답 후보 252개마다 모든 뜻을 담은 연상 단어를 가까운 순으로 직접 적었다(평균 25개, 모두 6,300개). 예: 나침반 → 북쪽·방향·동서남북·바늘·자석·지도… 목록 안 단어는 순서로 점수: 앞 5개 99.5 → 95.5, 그 뒤 94 → 80 (0.5 단위).
  - **목록 밖 단어**: 단어 벡터의 코사인을 S자 곡선 `88 / (1 + e^(−12 × (코사인 − 0.2)))` 로. 관련 없는 단어 0~15%, 조금 관련 40~60%, 뚜렷한 관련 75~85%, 88% 를 넘지 않는다. 정답을 품지 않으면서 글자만 나눠 가진 단어(나침반-받침대)는 절반.
  - 예: 사과 → 과일 99.5, 배 96.5, 빨강 93.5, 사죄 86.5, 나무 36, 세금 7 / 나무 → 소나무 98.5, 뿌리 97.5, 도토리 89.5, 버섯 86, 질책 5.9
- **컴퓨터**: 출제는 방송 출제자처럼 연상 목록의 중간·뒤쪽 단어 몇 개(쉬움 1~2개·목록 5~14번째, 보통 2~3개·7~20번째, 어려움 3~5개·10~30번째, 단계마다 3칸 가깝게)를 먼 것부터 낸 뒤 앞쪽(95% 이상) 단어 하나로 그 단계를 끝낸다. 예: 우산(어려움) → 하늘 81.5, 파라솔 83.5, 젖음 85, 장마 97.5. 맞히기는 힌트 유사도와 가장 잘 맞는 단어를 찾되 유사도를 흐릿하게 읽는다(표준편차 쉬움 110, 보통 60, 어려움 30 %p). 컴퓨터끼리 30차례: 맞히는 쪽 쉬움 8~11번 못 맞힘, 보통 2~5번, 어려움 0~1번. 피스는 쉬움 3차에만, 보통 2차부터, 어려움은 바로 쓴다.
- **온라인 대전**(커넥트4와 같은 틀): 빠른 대전, 방 만들기(4글자 코드·초대 링크), 재접속 토큰(새로고침해도 30초 안에 같은 자리로), 한 판 더(먼저 출제하는 쪽이 바뀜), 나가면 상대 승리, 없는 방 코드를 여러 번 대면 1분 막기, `maxPayload` 4KB.
  - **숨긴 단어는 서버만 안다**: 맞히는 쪽 브라우저에는 차례가 끝날 때까지 정답도, 출제자의 후보 5개도 보내지 않는다. 유사도 계산, 힌트 규칙 검사, 💡 추천도 서버가 한다(규칙 코드 `public/logic.js` 를 서버와 브라우저가 같이 씀).
  - **제한 시간**: 숨길 단어 고르기 30초(넘기면 첫 후보), 한 단계 힌트 3분(넘기면 서버가 남은 힌트를 채움), 한 단계 답 60초(넘기면 못 맞힌 것으로), 차례 결과 12초(둘 다 다음을 누르면 바로). 시험에서는 `SECRET_MS`·`HINT_MS`·`GUESS_MS`·`NEXT_MS` 로 줄인다.
  - 온라인 판은 전적에 넣지 않는다.
- **저장**: 난이도별 전적 `secretwordRec`, 로비 표시용 총 승수 `secretwordWins`, `secretwordMuted`.

## 단어 자료 (`public/data/`)

- `words.txt`: 한 줄에 `단어\t표시` (2 = 정답 후보 252개, 1 = 자주 쓰이는 낱말·연상 목록 낱말 5,341개, 0 = 사람이 써도 되는 단어). 20,707개. 처음 사전(fastText 명사 추출)에 공·골·붓·도로·일 같은 기본 낱말이 빠져 있어 연상 목록의 낱말 1,444개를 더했다.
- `assoc.json`: 위 「연상 목록」. 명사 목록은 fastText 어휘에서 뽑았다(`tools/nouns.js`·`build.js`·`pack.js`: 조사 붙은 꼴이 3개 이상 있으면 명사로 봄).
- `vecs.bin`: 단어마다 192개의 int8 (약 4.0MB). KURE-v1(연상 틀 4개: `{}`, `{}와 관련된 것`, `{}을 떠올리면 생각나는 것`, `{}의 여러 가지 뜻`) 40% + KR-SBERT(단어 틀 4개) 40% + fastText 20% 를 이어 붙여 PCA. 방송 기록으로 비교했을 때 가장 나은 조합(`tools/eval_show.py`), WS-353 0.79. 브라우저(컴퓨터 대전)는 `fetch` 로(`?v=` 자료 판 번호를 붙여 캐시를 피함), 서버(온라인 대전)는 시작할 때 읽는다.
- **어떻게 골랐나**: 한국어 단어 유사도 평가 데이터 **한국어 WS-353**(Park et al., ACL 2018 「Subword-level Word Vector Representations for Korean」, 원어민 14명이 매긴 353쌍)으로 후보를 채점했다(사람 점수와 코사인의 스피어만 상관, 게임 사전에 있는 259쌍):

  | 후보 | 점수 |
  |---|---|
  | fastText 한국어 300차원 (예전) | 0.609 |
  | KR-SBERT (단어만 / 문장 틀 평균) | 0.620 / 0.666 |
  | multilingual-e5-large | 0.647 / 0.674 |
  | bge-m3 | 0.638 / 0.703 |
  | **KURE-v1** (고려대, bge-m3 를 한국어로 더 학습) | 0.686 / **0.717** |
  | KURE-v1 문장 틀 평균 + 평균 빼기 (All-but-the-top, Mu & Viswanath 2018) | 0.760 |
  | KURE 35% + fastText 65% (한때 쓴 것) | 0.748 |
| **최종: KURE(연상 틀) + KR-SBERT + fastText 20% → 192차원 int8** | **0.79** (293쌍) |

  - 문장 틀: 단어 하나만 넣으면 문장 모델이 철자 조각에 끌려서(바나나 → 아바나·가나·나나) `{단어}`, `{단어}라는 단어`, `{단어}에 대해`, `{단어}의 뜻` 4개를 평균 냈다(문맥 틀로 정적 단어 벡터 만들기, Bommasani et al. 2020).
  - 그래도 KURE 만 쓰면 이웃 10개 중 72% 가 글자가 겹치는 단어(연필 → 수필·연꽃)라, 철자에 덜 끌리는 fastText 와 섞었다(메타 임베딩, Yin & Schütze 2016). 섞는 비율 35% 에서 점수는 거의 그대로(0.758)이고 글자 겹침은 40% 로 줄었다: 바나나 → 코코넛·파인애플·아몬드·오렌지·과일, 연필 → 볼펜·종이·잉크·필기, 피아노 → 바이올린·색소폰·첼로.
- 출처·라이선스: [KURE-v1](https://huggingface.co/nlpai-lab/KURE-v1) (고려대학교 NLP&AI, **MIT**), [fastText 한국어 Common Crawl 벡터](https://fasttext.cc/docs/en/crawl-vectors.html) (Facebook, **CC BY-SA 3.0**) → `public/data/` 는 CC BY-SA 3.0 을 따른다. 평가 데이터: [KoreanWordVectors WS353_korean.csv](https://github.com/SungjoonPark/KoreanWordVectors).
- 자주 쓰이는 낱말: `tools/common_words.txt` = [위키낱말사전 「부록:자주 쓰이는 한국어 낱말 5800」](https://ko.wiktionary.org/wiki/부록:자주_쓰이는_한국어_낱말_5800)(국립국어연구원 2004 「한국어 학습용 어휘」 6,000개에서 고유명사를 뺀 것, CC BY-SA). 예전엔 fastText 빈도로만 걸러서 트로츠키·호크스 같은 이름이 힌트로 나왔다. `tools/flag_common.js` 로 표시를 다시 매긴다.
- 다시 만들기(`tools/`, 원본 모델·벡터는 저장소에 넣지 않음): `embed_kure.py`(사전 전체를 KURE 문장 틀 평균으로, 약 1분), `mix_compress.py`(섞기·PCA·int8), `eval_ws353.py`(후보 비교). 파이썬 3.11 + `sentence-transformers`, `scipy`.

시험은 `node --test`. `test/logic.test.js`: 유사도 눈금(1위 99.99, 10위 95.00), 후보 5개·2라운드 남은 4개, 힌트 거절과 95% 이상이 나올 때까지 계속, 답은 맞음·틀림만(유사도 없음)·피스·넘기기·단계 점수, 1점·1+2+3점·2라운드 2배, 95% 이상 단어가 바닥난 단계, 연습 1라운드, 컴퓨터 힌트가 매 단계 95% 이상으로 끝나는지, 컴퓨터 답, 난이도 순서. `test/server.test.js`: 잘못된 주소·점 파일·큰 메시지, 출제자만 후보를 받고 맞히는 쪽은 정답을 못 받는지, 95% 이상까지 힌트·거절, 답은 맞음·틀림만·피스·넘기기·점수·출제자 교대, 아무도 안 하면 제한 시간으로 끝까지(출제자 1+2+3점), 나가기·한 판 더, 방 코드, 재접속, 방 코드 무차별 대입 막기.
